# v0.32 Speedup Verification (scala-torch 0.1.4-gh1, RTX 3090)

## Scope

Measured recent training-free diffusion acceleration methods implemented natively on `scala-torch` (`0.1.4-gh1`) with CUDA FP16 + cuDNN enabled on an NVIDIA GeForce RTX 3090:

- **FasterCache CFG-Cache** (`cfg_cache`, Lv et al., ICLR 2025, arXiv:2410.19355) + **Adaptive Guidance** (`adaptive_threshold`) + high-frequency boost (`hf_weight`), phase-locked to DeepCache scheduled full steps.
- **HiCache** (`deepcache.contraction`, Liu et al., arXiv:2508.16984): scaled-Hermite contraction (`contraction < 1.0`) damping higher-order TaylorSeer extrapolation inside DeepCache (`order = 1, 2`).
- **PostDiff Progressive Resolution** (`postdiff`, arXiv:2508.06160): two-stage resolution denoising with solver history reset and cache deferral (`deferUntil`) across transition + high-res warmup steps so stacked `PostDiff + FastMode` produces zero upscale/burn artifacts.
- **FirstBlockCache** (`fbcache`, evaluated and excluded): measured on SD1.5 and SDXL CNN U-Nets after `downBlocks(0).layers(0)`. `relL1` stayed at `0.34–0.50` across steps (0 skips at `threshold <= 0.34`); thresholds that actually skipped (`0.38–0.40`) introduced checkerboard artifacts under `CFG=7.0` (`5.84s` SDXL) and lost detail even at `CFG=1.0` (`4.61s` SDXL), while remaining significantly slower and lower quality than `HiCache`. Excluded cleanly before publishing `0.1.4-gh1`.

## RTX 3090 Benchmarks

Settings: `Euler a`, `Uniform`, `20 steps`, `CFG = 7.0`, `seed = 173`, `batch_size = 1`, cuDNN enabled (post-warmup worker process).

### SD1.5 (`animekawa_v10.safetensors`, 512×512)

| Configuration | Engine Time (s) | Speedup vs Baseline | Visual Notes |
|---|---:|---:|---|
| Baseline (20 steps) | 1.390 | 1.00× | Sharp silver hair, classroom window |
| `cfg_cache(start=0.25, interval=3)` | 1.229 | 1.13× | Nearly identical to baseline |
| `postdiff(scale=0.5, portion=0.4)` | 1.289 | 1.08× | Clean coarse layout shift |
| v0.31 Fast Mode (`DC int=3 f=5 ord=1, tgate=8, cfg=0.7`) | 1.028 | 1.35× | Slight blue/pink tint shift on SD1.5 |
| **v0.32 Fast Mode (`cand_C`: + `contraction=0.7, cfg_cache=3, tgate=10`)** | **1.018** | **1.37×** | **Crisp, eliminates v0.31 color shift on SD1.5** |
| Order-2 `HiCache (int=3 f=6 ord=2 c=0.75, cfg_cache=3, tgate=10)` | 1.000 | 1.39× | Clean detail |
| Aggressive `HiCache (int=4 f=4 ord=2 c=0.65, cfg_cache=4, tgate=8, cfg=0.65)` | 0.923 | 1.51× | Softer face/hair on SD1.5 (`interval=4` too aggressive for 512px) |

### SDXL (`waiIllustriousSDXL_v170.safetensors`, 1024×1024)

| Configuration | Engine Time (s) | Speedup vs Baseline | Visual Notes |
|---|---:|---:|---|
| Baseline (20 steps) | 6.331 | 1.00× | Sharp silver hair, desk & sunlit window |
| `cfg_cache(start=0.25, interval=3)` | 5.130 | 1.23× | Indistinguishable from baseline |
| `postdiff(scale=0.5, portion=0.4)` | 4.782 | 1.32× | Clean details |
| v0.31 Fast Mode (`DC int=3 f=5 ord=1, tgate=8, cfg=0.7`) | 3.499 | 1.81× | Clean |
| **v0.32 Fast Mode (`cand_C`: + `contraction=0.7, cfg_cache=3, tgate=10`)** | **3.481** | **1.82×** | **Crisp anime eye, hair & classroom lighting** |
| Aggressive `HiCache (int=4 f=4 ord=2 c=0.65, cfg_cache=4, tgate=8, cfg=0.65)` | 3.046 | 2.08× | Razor-sharp on 1024px SDXL |
| **`PostDiff(0.5, 0.4)` + Aggressive `HiCache FastMode`** | **2.797** | **2.26×** | **Under 2.8s on 1024×1024 SDXL, zero burn/upscale artifacts** |

## Summary

- `FastModePlugin` defaults to the balanced **`cand_C`** preset (`interval = 3, order = 1, contraction = 0.7, cfg_cache_interval = 3, gate_step = 10, guidance_until = 0.7`), delivering faster generation with improved color fidelity across both SD1.5 and SDXL.
- Advanced users can select `order = 2`, higher `interval`, lower `contraction` (`~0.65`), and opt-in **`PostDiffPlugin`** (`postdiff`) for up to **2.26×** speedup (`2.797s`) on 1024×1024 SDXL.
