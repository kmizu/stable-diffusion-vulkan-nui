# v0.33 / `scala-torch 0.1.5` Speed-Up Verification on RTX 3090

Measured on NVIDIA GeForce RTX 3090 (24 GiB, Windows 11, Java 25, `scala-torch 0.1.5`) using real SDXL (`waiIllustriousSDXL_v170.safetensors`, 1024×1024) and SD1.5 (`animekawa_v10.safetensors`, 512×512) checkpoints with prompt `"1girl, silver hair, school uniform, classroom, sunlit window, masterpiece"`, seed `173`, `cfg_scale = 7.0`.

## Implemented in `scala-torch 0.1.5`

1. **FlashAttention-2 32×32 Dispatch Fix (`CudaSession.scala`)**:
   - Enabled `h_fa2_w4r2c4` at `qt >= 1024, kt >= 1024` and `h_fa2_w4r1c{chunks}` at `qt >= 512, kt >= 512` instead of falling back to single-warp kernels on SDXL 1024×1024 / SD1.5 512×512 self-attention.
2. **SageAttention + SpargeAttn (`half.cu`, `CudaSession.scala`, default ON via `SCALATORCH_CUDA_SAGE_ATTN != "0"`)**:
   - Channel-mean smoothing on keys + per-block INT8 `QK^T` + FP16-accum `PV` + online warp-level log2 PV-skip (`skipDelta = 11.0f`) activated for large attention (`qt >= 2048 && kt >= 2048`, 4096×4096 SDXL high-res layers).
   - Microbenchmark (`2x10x4096x64`): cosine similarity `0.999996`, `2.148 ms -> 1.869 ms` (`1.15x`) in isolation and up to `2.85x` at `128`-head tiles.
3. **Dynamic W8A8 INT8 Linear & Fused GEGLU (`half.cu`, `Cublas.scala`, `CudaSession.scala`, `CudaDiffusionRuntime.scala`, default ON via `SCALATORCH_CUDA_W8A8 != "0"`)**:
   - Cached per-channel INT8 weight quantization (`IdentityHashMap`) + dynamic per-row INT8 activation quantization + `cublasGemmEx` (`CUBLAS_COMPUTE_32I`) + fused int32 dequant + bias + residual / GEGLU epilogue.
   - Restricted strictly to large FFN projections (`M >= 1024`, `M*N*K >= 8e9`, cosine similarity `0.999939` / GEGLU `0.999870`, `[2048,10240,1280]` `0.936 ms -> 0.488 ms` = `1.92x`), avoiding regression on smaller `[2048,1280,1280]` GEMMs.
4. **Limited Interval CFG (`CfgSchedule.activeStart`, `CfgSchedulePlugin`, `FastModePlugin`)**:
   - Skips early high-noise unconditional CFG passes when `progress < active_start` (`CFG = 1.0`, single conditional U-Net call). Default `guidance_from = 0.10` in `FastModePlugin`.
5. **Formal Align Your Steps (`DpmSchedule.paperAysZeroTerminal`, `NativeDiffusionBackend.scala`)**:
   - Added formal AYS 10–12 step schedules for `DPM++ 2M` (zero terminal sigma) and `Euler a` alongside `DPM++ 2M SDE`.

## Evaluated and Excluded (Quality-First Rule)

- **DaTo (`2×2` dynamic token pruning, ICLR 2025)**: Even at `keep=3`, caused severe hair/eye blurring on SDXL (`2.469 s`) and slowed SD1.5 (`1.406 s`). Cleanly removed before release.
- **Bottleneck Sampling (`PostDiff start_portion`, High→Low→High)**: Caused a localized RGB window artifact on SDXL (`2.782 s`) and hazy blur on SD1.5 (`0.797 s`), while being slower than `CandC + LI-CFG 0.10` (`2.672 s`). Reverted before release.
- **Stacking aggressive caching (`interval=2`) on 10-step AYS (`SD1.5`)**: Over-skipping CFG and DeepCache steps within a 10-step budget blurred SD1.5 (`0.609 s`); `12`-step AYS (`0.641 s`) or `AYS 10 + LI-CFG` without aggressive caching (`0.687 s`) remains crisp.
